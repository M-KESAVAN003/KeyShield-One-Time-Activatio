# Limitations
## What randomization does not protect against
- Screenshots, screen recording, or someone watching: the digits are visible.
- A malicious app or accessibility service that reads field contents or key labels.
- A rooted or compromised device.
- Text (QWERTY) input is not randomized.

## Android restrictions
- Some banking and UPI apps use their own PIN pad or reject third-party keyboards.
- A keyboard cannot tell whether a number field holds a PIN, OTP or amount.
- Apps that draw custom fields without declaring an input type get QWERTY.
- The user must enable and select the keyboard manually.
